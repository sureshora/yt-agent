# YT Agent

Coding-first AI agent for a daily YouTube technical-content workflow.

## Mission

YT Agent helps produce one high-quality YouTube Short and a companion long-form technical video from real AI-agent coding work. The workflow prioritizes real code, real execution, technical accuracy, curiosity-driven presentation, and human approval before publishing.

## YT-001

YT-001 establishes the project foundation and the first executable vertical slice:

1. Accept a content instruction.
2. Generate a structured content plan.
3. Produce a Short script and long-form outline.
4. Generate title, description, CTA, and production metadata.
5. Keep publishing behind explicit human approval.

## Principles

- Coding first.
- No fake demos.
- No shallow AI filler.
- No hidden shortcuts.
- Real implementation and test evidence should drive content.
- Short-form content creates curiosity for the complete long-form build.
- Human approval is required before publication.
